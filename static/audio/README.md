# Local audio files

Place only MP3 audio that you own or are licensed to distribute in this folder.

Example path to enter in the admin song form:
`/static/audio/my-track.mp3`

Use simple filenames with letters, numbers, dots, underscores, and hyphens. Do not upload copyrighted commercial songs without permission. Large files can make Git history and deployments heavy; use authorized object storage for larger libraries.
